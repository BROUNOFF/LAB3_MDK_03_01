# ИСУПС — информационная система полярной станции (Django + PostgreSQL)

## Запуск
```bash
docker compose up -d                      # PostgreSQL (arctic/arctic)
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo                # демо-данные
python manage.py runserver                # http://127.0.0.1:8000
python manage.py test                     # 12 тестов
# документация из docstring:
python -m pdoc station -o docs
```
Без PostgreSQL для проверки: `DB_ENGINE=sqlite`. Параметры БД: `DB_NAME, DB_USER, DB_PASSWORD, DB_HOST, DB_PORT`.

## Роли (группы Django) и демо-логины (пароль `demo12345`)
| Логин | Роль | Может |
|---|---|---|
| chief | Руководитель | смены, график дежурств, утверждение заявок, отчёты, всё остальное |
| meteo, glacio, radio | Специалист | вводить измерения, фиксировать НС |
| mech | Механик | калибровка приборов, моточасы/ТО, склад (топливо) |
| doc | Врач | здоровье персонала, склад (медикаменты) |

## Ключевые сценарии
1. Зачисление в смену + график дежурств (запрет назначать «не годен к дежурству»).
2. Ввод наблюдений с блокировкой приборов с просроченной калибровкой (модель + сервис + форма).
3. Калибровка приборов с журналом.
4. Склад: расход/приход, автозаявка при остатке ниже нормы, утверждение и приём поставки.
5. Дизель-генераторы: моточасы, ТО каждые 250 м/ч.
6. Журнал НС и отчёты руководителя (наблюдения по типам, расход, число НС, укомплектованность).

## Архитектура (MVC/MVT)
`models.py` — сущности и инварианты · `services.py` — сценарии (транзакции) ·
`forms.py`/`views.py`/`templates/` — ввод и серверный рендеринг · `permissions.py` — роли.
